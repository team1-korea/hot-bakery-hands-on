# Avalanche Bakery

> 이 디렉토리는 [avalanche-bakery](https://github.com/0u-Y/avalanche-bakery) `159eb3f` 시점의 스냅샷입니다.
> 화면 흐름 참고용이며, 이후 변경은 원본 레포에서 이루어집니다.

쿠키 클래스 현장에서 참가자의 사진이 증서가 되어 행사장 TV 진열장에 놓이는 과정을 보여주는 프론트엔드 프로토타입입니다. 백엔드, 외부 API, 환경변수 없이 목업 데이터만으로 동작합니다.

배포: [avalanche-bakery.vercel.app](https://avalanche-bakery.vercel.app)

## 경로

| 경로 | 용도 |
| --- | --- |
| `/` | 모든 프로토타입으로 이동하는 인덱스 |
| `/demo` | A/B·참가 인원·제출 흐름을 고른 뒤 한 세션을 실행하는 시작 화면 |
| `/demo?run=1&v=b&n=10&p=burst` | 설정을 건너뛰고 그 조건으로 바로 재생. 재생 중인 세션은 항상 이 주소로 남는다 |
| `/demo/a` | A가 미리 선택된 시뮬레이터 시작 화면 |
| `/demo/b` | B가 미리 선택된 시뮬레이터 시작 화면 |
| `/demo/c` | 이전 링크 호환용. 새 `/demo` 시작 화면으로 이동 |
| `/join` | 제출 뒤 휴대폰이 달라지는 A안·B안을 나란히 비교하고 고르는 화면 |
| `/join/a` | 제출 뒤 자동 진행하고 앞 화면으로 시선을 넘기는 안 |
| `/join/b` | 제출 이후 네 단계를 폰에서 자동으로 설명하는 안 |
| `/join/c` | 운영자 안내 뒤 참가자가 `오븐에 넣기`를 직접 누르는 안 |
| `/display` | 15명이 3명씩 몰아서 제출하는 30초 행사장 TV 데모 |
| `/display?dev=1` | 참가자·상태·화면 모드를 직접 조작하는 행사장 TV |
| `/styleguide` | 디스플레이 시각 방향 검토 화면 |

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열고, 팀 리뷰는 `/demo`부터 시작합니다. A/B와 1~15명의 참가 인원, `몰아서` 또는 `차례로` 제출을 고르고 `시뮬레이션 시작`을 누르면 한 번의 세션이 재생됩니다. 화면 위의 `휴대폰`·`TV`로 관찰 화면을 바꿔도 참가자와 발행 상태는 그대로 이어집니다. `세션`을 열면 다른 참가자의 폰, 재생·정지, 처음부터, 설정으로 돌아가기를 사용할 수 있습니다.

모든 전체화면 좌측 상단(또는 조작 바 왼쪽)에는 같은 모양의 `‹ 되돌아가기`가 있습니다. 재생 중인 데모 세션은 주소에 남으므로 브라우저 뒤로 가기가 설정 화면으로 돌아오고, 같은 주소를 다시 열면 같은 조건이 재생됩니다.

시나리오 B에서는 네 단계가 진행되는 동안 화면 아래에 만들어지는 증서가 함께 있고 `크게 보기`로 증서를 열 수 있습니다. 네 단계가 끝난 완료 화면에서는 `증서가 만들어진 과정 다시 보기`로 같은 네 단계를 패널에서 다시 봅니다.

`몰아서`는 세 명 단위 제출이 짧은 간격으로 들어와 작업대와 오븐에 여러 카드가 함께 머뭅니다. 데이터 처리는 병렬로 진행하지만 TV에서 구역을 넘는 카드는 최대 두 장으로 제한해 각 쿠키의 이동을 추적할 수 있게 했습니다. 참가자 공통 입력은 로그인·사진·이름·제출의 네 단계이며, TV 노출과 공개 증서 안내는 마지막 제출 화면에서 확인합니다.

시뮬레이터 키보드 조작은 아래와 같습니다.

| 키 | 동작 |
| --- | --- |
| `P` / `T` | 휴대폰 / TV 화면으로 전환 |
| `Space` | 재생 / 일시정지 |
| `R` | 선택한 조건으로 처음부터 재생 |
| `Esc` | A/B·인원 설정 화면으로 돌아가기 (되돌아보기 패널이 열려 있으면 패널만 닫습니다) |

## 서버 없이 공유하기

[avalanche-bakery-review.html](./avalanche-bakery-review.html)은 CSS, JavaScript, Archivo Black, Gothic A1을 모두 포함한 단일 파일입니다. 파일을 그대로 보내고 더블클릭하면 인터넷 연결 없이 열립니다. 메신저가 HTML 첨부를 막으면 [avalanche-bakery-review.zip](./avalanche-bakery-review.zip)을 보내면 됩니다.

- 상단 선택 메뉴 또는 `←` / `→`: A·B·C와 TV 상태 장면 전환
- `숨기기` 또는 `H`: 리뷰 조작기 숨김/표시
- URL의 `#display-shelf-8` 같은 해시: 특정 장면을 바로 열어 공유

이 파일은 피드백용 정지 장면 모음입니다. 실제 연속 재생과 카드 이동은 `/demo`에서 확인합니다.

## 같은 네트워크의 실기기에서 보기

개발 컴퓨터와 휴대폰을 같은 Wi-Fi에 연결한 뒤 개발 서버를 모든 네트워크 인터페이스에 엽니다.

```bash
npm run dev -- -H 0.0.0.0
```

개발 컴퓨터의 LAN IP를 확인하고 휴대폰 브라우저에서 `http://<LAN-IP>:3000/join/a`처럼 접속합니다. 예를 들어 컴퓨터 주소가 `192.168.0.20`이면 `http://192.168.0.20:3000/demo`입니다. 사진 단계의 `카메라 열기`는 모바일 브라우저의 후면 카메라 입력을 우선 요청합니다.

## `/display?dev=1` 조작키

| 키 | 동작 |
| --- | --- |
| `1` / `5` | 참가자 1명 / 5명 추가 |
| `A` | 전체 다음 상태 |
| `N` | 선택한 참가자 다음 상태 |
| `Space` | 2~4초 자동 진행 토글 |
| `F` | 실패 1건 주입 |
| `L` / `G` / `S` | LIVE / GALLERY / SLIDES |
| `Q` | QR 표시 토글 |
| `R` | 빈 LIVE 상태로 초기화 |

오븐에 들어간 카드는 다음 명령이 바로 와도 최소 2초 머뭅니다. `GALLERY`는 진열장 요소를 유지한 채 중앙으로 확장합니다.

## 목업 이미지와 배포 확인

`public/mock/cookie-1.svg`부터 `cookie-15.svg`까지 팔레트 기반 자리표시자가 있습니다. 15번은 세로 원본의 정사각 크롭 확인용입니다. 실제 사진이 없거나 로드에 실패해도 회색 상자 대신 CSS로 만든 쿠키·증서 그림이 남습니다.

Vercel 배포 전 확인 명령은 아래와 같습니다. 현재 런타임 환경변수와 외부 API 호출은 없습니다.

```bash
npm run lint
npm run build
```

## 디자인 하네스

화면 결정은 `PRODUCT.md`와 `DESIGN.md`에 남기고, 검토와 안티패턴 점검에는 [impeccable](https://github.com/pbakaus/impeccable)을 씁니다. 설치본(`.claude/skills/`)은 저장소에 넣지 않으므로 각자 받습니다.

```bash
npx impeccable install --providers=claude --scope=project
node .claude/skills/impeccable/scripts/detect.mjs app components
```
